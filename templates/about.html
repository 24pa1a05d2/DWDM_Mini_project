E-Commerce Customer Segmentation & Sales Intelligence System

B.Tech CSE Mini-Project | Subject: Data Warehousing and Data Mining (DWDM)

Problem Statement

Modern e-commerce enterprises generate massive volumes of transactional data daily. However, raw flat transaction tables fail to provide actionable strategic clarity regarding customer purchasing behaviors, high-value customer groups, sales trends across regions, or inactive/at-risk customers facing churn.

This project solves this challenge by transforming raw, unstructured e-commerce transactions into structured business intelligence using Data Warehousing (Star Schema DDL, ETL) and Data Mining (OLAP, RFM Analysis, K-Means Clustering).

Core System Objectives

  • Automated ETL Pipeline: Extract CSV data, perform deduplication, data validation, date normalization, and load into a Star Schema.
  • Multidimensional OLAP Engine: Support Roll-Up, Drill-Down, Slice, and Dice operations over time, product, and location dimensions.
  • RFM Behavioral Scoring: Compute Recency, Frequency, and Monetary metrics with quantile scoring (1-5 scale).
  • K-Means Clustering: Standardize RFM features using StandardScaler, compute WCSS for Elbow curve analysis, and assign human-readable segment profiles.

1. Star Schema Data Warehouse Design

The Data Warehouse uses a classic Star Schema structure consisting of a central FACT_SALES table surrounded by 4 normalized dimension tables:

  • FACT_SALES: Stores numeric metrics (quantity, unit_price, total_amount) and foreign key IDs.
  • DIM_CUSTOMER: Attributes (customer_id, customer_name, gender, age, location).
  • DIM_PRODUCT: Attributes (product_id, product_name, category, subcategory).
  • DIM_DATE: Attributes (date_id, full_date, day, month, month_name, quarter, year).
  • DIM_LOCATION: Attributes (location_id, city, state, region, country).

2. K-Means Customer Segmentation

K-Means partitions $N$ customer samples into $K$ distinct clusters based on RFM features:

  1. Standardization: Features are normalized using StandardScaler ($\mu=0, \sigma=1$) to prevent monetary magnitude bias.
  2. Elbow Method: Calculates Within-Cluster Sum of Squares (WCSS) across $K \in [1, 10]$ to locate the inflection ("elbow") point.
  3. Centroid Profiling & Labeling: Cluster centroids are analyzed against dataset medians to assign meaningful labels (e.g. High-Value Champions, At-Risk Customers, Loyal Customers).
